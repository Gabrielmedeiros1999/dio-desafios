# Desafio Criativo: Extraindo Insights do Feedback de Clientes Bancários

## 📖 Sobre o desafio

Este projeto foi desenvolvido como parte de um desafio da DIO. O objetivo é criar um prompt estruturado para orientar uma Inteligência Artificial na análise de feedbacks de clientes bancários, permitindo identificar padrões, oportunidades de melhoria e gerar recomendações úteis para a tomada de decisão.

## 🎯 Objetivo

Desenvolver um prompt capaz de orientar uma IA a:

- Identificar reclamações recorrentes;
- Reconhecer elogios e pontos positivos;
- Encontrar oportunidades de melhoria;
- Organizar os resultados de forma clara e objetiva.

## 📝 Prompt Final

### Papel da IA

Atue como analista de experiência do cliente em um banco.

### Objetivo

Sua tarefa é analisar feedbacks de clientes sobre serviços digitais do banco para identificar reclamações frequentes, elogios, oportunidades de melhoria e os principais problemas enfrentados pelos clientes.

### Contexto

A análise será utilizada pela equipe de experiência do cliente para identificar os principais pontos de melhoria nos serviços digitais e apoiar a tomada de decisões sobre futuras melhorias no aplicativo e nos canais de atendimento.

### Dados disponíveis

A base contém:

- Data do comentário;
- Texto do feedback;
- Nota de avaliação;
- Canal de atendimento utilizado.

### Instruções de análise

1. Classifique os feedbacks por sentimento, urgência e impacto na experiência do cliente.
2. Identifique os principais padrões, problemas, elogios e oportunidades de melhoria.
3. Aponte evidências utilizando apenas os dados fornecidos.
4. Sugira ações práticas para a equipe responsável pelos serviços digitais.

### Formato da resposta

A resposta deve conter:

- Um resumo executivo com até cinco linhas;
- Uma tabela contendo tema, sentimento, evidência e ação sugerida;
- Uma lista com as três principais prioridades de melhoria.

### Restrições

- Utilize apenas os dados fornecidos.
- Não invente números, causas ou conclusões.
- Não exponha dados pessoais ou sensíveis.
- Informe limitações quando os dados não forem suficientes.
- Utilize linguagem clara, objetiva e voltada para a tomada de decisão.
